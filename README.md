# Mayank Website New

Mayank is a curated exchange for buying, licensing and continuing useful digital products, code, domains and design systems.

This repository contains only the new premium Mayank website. The legacy codebase remains outside this folder and is not part of this deployable export.

## Local development

```bash
npm install
npm run dev
```

## Vercel

Import this repository into Vercel as a Next.js project. No custom output directory is required.

- Build command: `npm run build`
- Start command: `npm run start`
- Node.js: 20.9 or newer
